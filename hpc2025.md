`[BRACKETS]` mean you have to change something.

First, log into the VPN:

```bash
ssh -p222 [USERNAME]@login-theia.rc.sc.edu
```

Then, request an interactive development session with the GPU:

```bash
idev_gpu
```

Your prompt should change from `login001` to, e.g., `node034`.


Now let's go to our work directory:

```bash
cd /work/[USERNAME]
```

Replace `[USERNAME]` with your username, like `rcstud12`. 

Then, make a new environment called `cnn`:

```bash
python -m venv cnn
```

When it prompts you, type `y` and hit Enter. Then activate it with

```bash
conda activate cnn
```

Your prompt should change.

Now we can install the packages we need. This can be tricky, but for this script it's not so bad. You can execute

```bash
TMPDIR=. pip install torch==2.6.0 torchvision==0.21.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cu124```
```

We can then get our script through several means, but one is uploading it to a service and downloading it:

```bash
wget https://raw.githubusercontent.com/nicholas-miklaucic/ai4sci-materials-2024/refs/heads/main/testcnn.py
```

Now, we can run it and see what happens:

```bash
python testcnn.py
```
